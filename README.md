# ZUSASS

This is a project built on LWJGL3 to create a 3D swords and spells sandbox type game.

Feel free to use anything in this repo that you'd like for any reason.
	If you do use anything, I only ask that you credit this GitHub repo.

# Maven builds
zgame is the core game library
Run `mvn install` in `/zgame` to build it separately

zusass is the core game
Run `mvn install` at the repo root to build a jar
